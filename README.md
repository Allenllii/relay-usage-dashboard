# 中转站用量面板

查询 AI 中转站的上游用量和客户用量，打开网页、填上自己的凭证就能用。

- **上游用量（百度）**：读取百度《数据查询接口》（`/api/v1/usage`、`/api/v1/api-keys`），按 Key / 模型查看用量和金额（人民币、美元分开统计）。
- **客户用量（new-api）**：读取 new-api 管理员只读接口，按客户 / 模型 / 渠道查看调用次数、Token、消费、客户余额，并在余额不足时提醒。

地址填 `demo` 可以先看演示数据。

## 两种用法

### 网页模式（直接打开 GitHub Pages）

凭证只在你的浏览器和对应服务之间传输，不经过任何第三方服务器；不勾选「在本机记住」时，浏览器不保存凭证。

| 功能 | 网页模式 |
|---|---|
| 百度 · API Key（`sk-`） | 可以直接用 |
| 百度 · AK/SK | 不支持：签名需要的 `x-bce-date` 请求头不在百度允许的跨域请求头里，请用本地模式 |
| new-api | 需要 new-api 允许本页面跨域访问。连接失败时，页面会给出可直接复制的 Nginx 配置 |

### 本地模式（支持全部功能）

需要 Node.js 18 或更高版本，不需要安装其他依赖：

```bash
node server.js
```

然后打开 http://127.0.0.1:8787 。请求由本机 `server.js` 转发，支持百度 AK/SK 签名，new-api 也不需要开放跨域。

想预填凭证，可以把 `config.example.json` 复制为 `config.json` 再填写。`config.json` 已在 `.gitignore` 中，不会被提交。

## 凭证说明

- **百度**：账号下任意一把可用的 `sk-` Key，或百度云 AK/SK（只能用本地模式）。注意：同一账号下任意一把有效 Key 都能看到整个账号的用量。
- **new-api**：用管理员账号在「个人设置 → 安全」里生成访问令牌，权限只勾「日志读取」和「用户读取」。旧版 new-api 还需要填写用户 ID。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面 |
| `models.js` | 百度模型清单（端点编码 ↔ 模型名） |
| `demo.js` | 演示数据 |
| `server.js` | 本地模式服务：转发请求、AK/SK 签名 |
| `test-sign.js` | 用百度官方文档示例校验签名实现：`node test-sign.js` |
